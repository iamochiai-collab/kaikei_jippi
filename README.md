# 計算書メーカー

実費徴収金計算書（別紙４）を、入れるだけでつくるWebアプリです。

1. 品目名を入れる（教科・活動・品名をえらぶと「数学「買い物学習」代」の形にまとまります）
2. 領収書の合計金額と、児童生徒・職員の名前を入れる（2人分の人は「×2」）
3. 買った数を入れて、あまりは「残り指導者買い切り」で指導者の分に
4. 「Excelで出す」で、学校の別紙４と同じ様式のExcelファイルに書きこんで保存（印刷・PDFもできます）

- 1人あたりの金額は、もとのExcelと同じく 1円未満切り捨てです
- 買った数や×のある人がいるときは、説明文（何枚入りを何こ買い、どう使ったか・1枚あたりの計算）を自動でつくり、Excelではテキストボックスで入れます
- 入力した内容はブラウザの中だけに保存されます（インターネットには送られません）
